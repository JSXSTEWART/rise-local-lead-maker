🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: PM2 won't start
  → Check logs: pm2 logs rise-api --err
  → Rebuild: cd rise-local-lead-creation/api && npm run build
  → Restart: pm2 restart rise-api

Issue: Database connection error
  → Verify .env: cat rise-local-lead-creation/api/.env | grep DB_
  → Test MySQL: mysql -h localhost -u apex2600_riselocal -pRiseleads2025\!Secure apex2600_riselocal -e "SELECT 1;"

Issue: 502 Bad Gateway
  → Check API: curl http://localhost:3001/
  → Check PM2: pm2 status
  → Check proxy: cat ~/public_html/.htaccess | grep -i proxy

Issue: Google Sheets export fails
  → Check credentials: grep GOOGLE_ rise-local-lead-creation/api/.env
  → Check logs: pm2 logs rise-api --err
